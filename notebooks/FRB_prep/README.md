# Prepping observational FRB data

For completeness, the notebooks are added that were used to pre-process raw FRB data files, which are available for download [here](https://www.canfar.net/storage/vault/list/AstroDataCitationDOI/CISTI.CANFAR/23.0029/data/beamformed_files). These notebooks were provided by Daniela Huppenkothen. 

Processed FRB data is stored in the `.dat`-files in the observational_data folder.
